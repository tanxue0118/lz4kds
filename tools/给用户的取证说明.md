# 给用户：设备取证操作说明

> 你好！要为你的手机编译 **LZ4KDS侧载** 模块（LZ4KD + SDDC 内存压缩算法侧载），
> 需要先从手机上采集几份文件。全程 5 分钟，**只读取，不改动任何东西**。
> **前提：手机已解锁 Bootloader，并装有 KernelSU 或 Magisk（能执行 su）。**

## 第一步：把取证脚本推到手机

电脑上执行（手机打开 USB 调试并授权）：

```bash
adb push recon.sh /data/local/tmp/
```

## 第二步：手机上执行

```bash
adb shell
su
sh /data/local/tmp/recon.sh
```

屏幕会逐行打印采集进度，最后显示：

```
[recon] DONE: /sdcard/lz4kds_recon_<机型>.tgz (大小)
[recon] 回传: adb pull /sdcard/lz4kds_recon_<机型>.tgz
```

## 第三步：回传文件

```bash
adb pull /sdcard/lz4kds_recon_<机型>.tgz
```

把这个 `.tgz` 发给适配者即可。

## 采集了什么（完全透明）

| 内容 | 用途 |
|---|---|
| 内核版本号、设备型号、SoC | 确定编译目标 |
| 内核配置（`/proc/config.gz`） | 编译参数 |
| `/vendor/lib/modules/` 下的 `.ko` 文件 | 提取内核符号 CRC（编译对齐用） |
| `/proc/kallsyms` 符号名（地址已去除） | 加载前符号校验 |
| zram 当前状态、内存信息 | 记录原厂参数，便于回退 |
| 设备指纹 | 防止把包发错人 |

## 安全吗？（重要，请放心）

**这个脚本只读不写。** 具体来说：

- ✅ 只读取系统文件，**不修改任何内容**
- ✅ 唯一写入位置是 `/sdcard`（你自己的存储卡/用户数据区），用来放采集结果
- ✅ **完全不接触** boot、persist、modem、tz（TrustZone）、vbmeta、super、xbl 等敏感分区
- ✅ 不改 SELinux、不改系统分区、不刷任何东西
- ✅ 不联网、不上传、不改你的数据
- ✅ **不采集 boot.img**（避免文件过大，也避免任何分区读取风险）

脚本跑完后手机上只多出一个 `/sdcard/lz4kds_recon_<机型>.tgz` 压缩包和一个 `/sdcard/lz4kds_recon/` 文件夹，
不想要了直接删掉即可。

## 采集完后能获得什么

- 定制版 **LZ4KDS侧载** 模块 zip（LZ4KD + SDDC 跨页去重，参考压缩比 ~5x）
- 模块只做算法侧载，**容量和算法请在系统侧自行设置**
- 回退方式：KernelSU 管理器里禁用模块 → 重启 → 恢复原厂 zram
- 若你的设备内核不支持（16K 页 / zram 编译进内核 / 无内核源码），会明确告知并说明原因
